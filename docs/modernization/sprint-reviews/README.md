# Sprint Reviews

Copy the template below to `sprint-N.md` at the end of each sprint. A sprint is not closed until required evidence is linked and unfinished work is re-planned.

## Template

```markdown
# Sprint N Review

- Dates/capacity:
- Sprint goal:
- Result: passed | partial | failed
- Constitution version checked:

## Completed stories and tasks

- [x] ID — evidence

## Demo

Observable workflow demonstrated with fixture/project and result.

## Verification evidence

| Check | Command or procedure | Result | Artifact |
|---|---|---|---|

## Issues, solutions, and learnings

- Issues opened/resolved:
- Solutions added:
- Learnings added:
- ADRs added/superseded:

## Metrics and risks

- Relevant measurements:
- New or changed risks:
- Constitution exceptions and expiry:

## Unfinished work

Task IDs, reason, and destination sprint/backlog.

## Next sprint readiness

Dependencies, research, and decisions required before commitment.
```
