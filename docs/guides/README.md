# Living Guides

`user-guide.md` documents only verified modern-app behavior. `developer-guide.md` is the operating manual for contributors and release maintainers.

## Update rule

The author of a change updates affected guide sections in the same change when it modifies user workflow, setup, configuration, diagnostics, compatibility, build/test commands, release steps, dependencies, or inclusion/attribution obligations. If that cannot happen, record an issue with owner and review date before merge.

At phase/release closure, review both guides against the active specification, verification evidence, `CHANGELOG.md`, `VERSIONING.md`, `NOTICE.md`, and the software-inclusion register.
